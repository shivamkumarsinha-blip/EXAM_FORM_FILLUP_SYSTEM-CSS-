# 🎓 Exam Form Fillup System

A responsive multi-page **Exam Form Fillup System** developed using **HTML5** and **CSS3**. This project demonstrates the design of an online examination form system with multiple pages for students and administrators.

## 📌 Features

- 🏠 Home Page
- 👨‍🎓 Student Registration
- 🔐 Student Login
- 📝 Exam Form Fillup
- 📋 Student Dashboard
- 👨‍💼 Admin Login
- 📂 Manage Exam Forms
- 📱 Responsive User Interface
- 🎨 Modern CSS Styling
- 🧭 Easy Navigation Between Pages

---

## 🛠️ Technologies Used

- CSS3

## 🚀 How to Run

1. Clone the repository

```bash
git clone https://github.com/shivamkumarsinha-blip/EXAM_FORM_FILLUP_SYSTEM-CSS-.git
```

2. Open the project folder.

3. Double-click **index.html**
   **OR**

4. Open the folder in **Visual Studio Code** and run it using the **Live Server** extension.
